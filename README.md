# XERXES Ghana

XERXES Ghana is an environmental intelligence research and monitoring platform under the broader XERSXES technology vision.

## Project status

Initial repository setup. The first milestone focuses on a reproducible application foundation, geospatial data workflows, and responsible evidence handling. No public whistleblower submissions or live drone operations are enabled.

## Workflow

- `main`: reviewed release-ready changes only.
- `develop`: integration branch.
- `feature/*`: scoped implementation branches, reviewed through pull requests.

See the project-foundation branch for the initial application scaffold.
