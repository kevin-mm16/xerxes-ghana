# Geospatial processing

Reserved for reproducible satellite workflows (Sentinel-2, cloud masking, spectral indices, change detection, GeoJSON output).

**First experiment:** one Ghanaian study area, two comparable seasonal windows, explicit quality masks, and a human-reviewed interpretation. Do not equate land-cover disturbance with proof of illegal mining.

Implement as separate workers once data requirements are defined. Track source data licenses, provenance, coordinates and spatial/temporal validation.
