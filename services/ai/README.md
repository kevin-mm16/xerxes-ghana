# AI research

Reserved for custom environmental models, training code, evaluation and model documentation.

**Initial goal:** compare a transparent spectral-index baseline against a small trained classifier with geography-held-out evaluation. Report precision, recall and limitations.

Do not commit raw datasets, model weights or identifiable source data to Git. No automatic public accusation should be derived from model predictions.

See [the inference/publication boundary](../../docs/imagery-and-ai-contracts.md). Public AI layers currently return no records; synthetic confidence values have been removed from the live map.
