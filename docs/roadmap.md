# 90-day research and MVP roadmap

These are planning targets for two developers, not guaranteed delivery commitments.

## Weeks 1–2: foundation
- [ ] Confirm acceptance criteria for one Ghana study area
- [ ] Test API + frontend + PostGIS locally
- [ ] Add database migrations and versioned API schema
- [ ] Set up CI, review rules and threat-model draft

## Weeks 3–6: environmental monitoring
- [ ] Study-area ingestion and map view
- [ ] Sentinel-2 imagery catalog and cloud-masked visualizations
- [ ] Date comparison and spectral indices
- [ ] Moderator workflow using synthetic or non-sensitive test reports

## Weeks 7–10: evaluation
- [ ] Establish labelled dataset and provenance
- [ ] Implement transparent index-based baseline
- [ ] Train and evaluate initial model on spatially held-out data
- [ ] Document limitations and false positives

## Weeks 11–12: stabilization
- [ ] End-to-end demonstration
- [ ] Automated tests and backup restore drill
- [ ] Demonstrate synthetic drone-node messages only if core MVP is stable
- [ ] Prepare funding demonstration and independent security review plan

**Excluded from MVP:** public confidential whistleblower intake, live UAV operations, drone radio mesh, production anonymity claims.
